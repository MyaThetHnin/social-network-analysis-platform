# YouAnalyze – Social Network Analysis Platform

## Overview

YouAnalyze is a web-based analytics platform developed by a five-member team to help content creators and businesses analyze YouTube channel performance using Social Network Analysis (SNA). The platform integrates the YouTube Data API to retrieve channel data, generate network visualizations, provide audience insights, and support data-driven decision-making.

## Features

- User registration and authentication
- Role-based access control
- YouTube Data API integration
- Social Network Analysis (SNA) visualization
- Channel performance analytics
- Audience engagement insights
- Predictive channel growth analysis
- Business analytics dashboard
- Admin dashboard
- Subscription and user management
- User feedback and support system
